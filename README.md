# Hundesalon Giunia 🐾 | Exklusiver Hunde- & Katzensalon

Moderne, elegante und voll responsive Website für den Hundesalon **Hundesalon Giunia** in deutscher Sprache.

## ✨ Features
- **Design & Ästhetik:** Butikowy luksus w palecie **Boutique Ruby & Cashmere** (harmonijnie zgrany z oryginalnym logo salonu).
- **Leistungen & Preise:** Interaktiver Preiskatalog mit Filterung nach Tiergröße (Kleine, Mittlere, Große Hunde, Katzen und Spezialbehandlungen).
- **Terminrechner & WhatsApp-Buchung:** Interaktives Buchungsmodul mit automatischer Preis- und Zeitschätzung sowie 1-Klick-Übertragung an WhatsApp.
- **Vorher & Nachher:** Interaktive Verwandlungs-Galerie mit Bildumschaltung.
- **Kundenstimmen:** Google-Bewertungen mit 4.9★ und authentischen Erfahrungsberichten.
- **Häufige Fragen (FAQ):** Übersichtlicher Akkordeon-Bereich für Tierhalter.
- **Rechtliches (DSGVO):** Integrierte Modale für Impressum, Datenschutzerklärung und AGB/Salonordnung.

## 🛠️ Tech Stack
- **React 19**
- **TypeScript**
- **Vite 8**
- **Tailwind CSS v4**
- **Lucide Icons**

## 🚀 Lokale Entwicklung

```bash
# Abhängigkeiten installieren
npm install

# Entwicklungsserver starten
npm run dev

# Produktions-Build erstellen
npm run build
```
